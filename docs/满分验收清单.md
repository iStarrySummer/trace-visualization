# 满分验收清单

## 研究与数据

- [ ] 研究问题具体，措辞为可由数据回答的“差异/关系”，不宣称因果。
- [ ] 至少 3 类任务、2 种提示策略、72 次左右独立运行，消息总数 ≥150。
- [ ] 模型版本、参数、工具权限、任务与测试在比较组间一致，运行顺序随机化。
- [ ] 原始数据有只读备份，提交的是匿名化副本；数据来源、同意与 AI 使用范围写清楚。
- [ ] 数据字典说明字段含义、来源、类型、缺失原因和派生规则。
- [ ] 清洗日志能复现去重、匿名化、类型转换、缺失统计和分类。

## 分析与图表

- [ ] 首次通过率、最终完成率、错误恢复率、修复轮次、工具调用和时长定义无歧义。
- [ ] 至少 5 条发现：2 条一/二维、2 条三维以上、1 条异常或局限。
- [ ] 每条发现能指向具体图表、筛选条件、样本量和统计值。
- [ ] 策略轨迹使用 `params + calculate + filter + opacity` 并预插值 48 帧；累计排名使用 `window(rank)`，两者的播放、暂停和进度拖动均正常。
- [ ] 区间刷选使用 `interval + filter param + vconcat`；滚动趋势使用 `window(mean, stdev) + area y/y2`；回归诊断使用 `layer + regression + groupby`。
- [ ] 相关性热力图使用 `rect + text` 发散色板；山脊图使用 `density + facet row`；成功率轨迹使用 `nearest + rule`；缩放探索使用 `bind: scales`。
- [ ] 九个 Vega-Lite 视图、路径图、任务矩阵、时间线和详情面板均有必要的标题、单位、图例或直接标注，且不是无目的堆图。
- [ ] 玫瑰红始终表示直接提示、青绿始终表示结构化反思；失败另有十字形状与文字编码，不使用无意义 3D。
- [ ] 报告只使用“相关、伴随、观察到”等描述性措辞，不把差异直接解释为因果。

## 系统与答辩

- [ ] 从全新目录按 README 可生成数据并启动页面，路径均为相对路径。
- [ ] 所有筛选能同步更新指标与九图；矩阵、路径、回归图和缩放图能驱动详情联动。
- [ ] Vega、Vega-Lite 与 vega-embed 成功载入，九个高级图没有 fallback，浏览器控制台无错误或警告。
- [ ] 在约 390 像素宽的移动视口中，九图改为单列并可在图内横向滚动，不撑破页面。
- [ ] 页面明确区分演示数据与真实数据，不提交演示结论冒充实证结果。
- [ ] 选取一个异常运行，能沿时间线解释错误、诊断、修改和最终状态。
- [ ] PPT 8～12 页，视频 5～6 分钟，成员都能解释指标、分类规则和关键代码。
- [ ] 正式提交前关闭开发服务器，清理个人路径、密钥、缓存和未匿名化文本。
